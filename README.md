# AI Case Management System (AICMS)
ระบบรับแจ้งและบริหารจัดการเบาะแสยาเสพติดด้วยปัญญาประดิษฐ์

Basic Requirement
=================
- ระบบ case management สำหรับรับแจ้งเบาะแสยาเสพติด ที่เชื่อมต่อกับระบบโทรศัพท์ที่สามารถทำ speech to text และสามารถแยกข้อมูลลงตาม field รวมทั้งสามารถแก้ปัญหา Case ซ้ำ
- จำนวน 10 คู่สาย
- ระบบเป็น on-premise และ Local AI ทั้งหมด
- ใช้ Model AI ขนาด 70B
- เชื่อมกับระบบโทรศัพท์เดิมที่มีอยู่ (Brand CISCO)
- ปัจจุบันรองรับ 6000 คู่สายต่อเดือน
